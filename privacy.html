Privacy policy

Last updated: 14 November 2026

Vtoroy mozg is a personal, non-commercial application used only by its owner. It is not offered to the public.

What data is accessed

With the owner's consent, the application reads the owner's Gmail messages using the read-only permission gmail.readonly. It cannot send, delete or modify email.

How data is used

Messages are analysed automatically to find deadlines, bills, fines and official letters, add them to the owner's personal task list and prepare reply drafts that the owner reviews and sends personally. For this analysis, message text may be processed by the Anthropic Claude API.

Storage and sharing

Results are stored on the owner's private server and are visible only to the owner. Data is not sold, not used for advertising and not shared with anyone else. Access can be revoked at any time in the Google Account under Security → Third-party connections.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Кратко по-русски: приложение личное, читает только почту своего владельца и только на чтение; письма анализируются автоматически (в том числе через Claude API) для списка дел и черновиков ответов; данные хранятся на личном сервере владельца, никому не передаются и не продаются.
